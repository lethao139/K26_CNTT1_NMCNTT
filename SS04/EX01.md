
## Part 1: Analysis

### 1. Wrong storage location
- Nam saves files in `C:\Windows\System32\...`
- `System32` is a core Windows folder, not for personal files.
- Reinstalling Windows / formatting C: can delete all his homework.

### 2. Wrong file/folder naming
- `Bai Tap Cua Nam`, `Session 01`, `bai tap 1.py` have spaces and inconsistent capitalization.
- In Terminal/CMD, spaces break paths unless quoted.
- Should use `kebab-case` or `snake_case`.

### 3. Network speed misunderstanding
- `100 Mbps` = `100 / 8 = 12.5 MB/s`.
- Browser showing `12.5 MB/s` is correct, not a scam.
- 1 GB file ≈ `1024 MB / 12.5 = 81.92s` (~1m22s).

### 4. Why SSD 256 GB shows less
- Manufacturers use `1 GB = 1000^3 bytes`.
- Windows uses `1 GiB = 1024^3 bytes`.
- `256 GB ≈ 238.4 GiB`.
- Windows, recovery, and reserved partitions take extra space.
