## Part 1: Analysis

### Why absolute path fails on another machine
- Absolute path like `C:\Users\Admin\Shopee-Lite\assets\logo.png` only works on your PC.
- Your friend’s PC has a different username, drive, and folder structure.
- Python cannot find the file -> `FileNotFoundError`.

### IPO flow: Storage -> RAM -> CPU -> Output
| Stage | Description |
|---|---|
| Input | Image file loaded from Storage (`assets/logo.png`) |
| Process | File read into RAM -> CPU decodes/processes image -> app renders UI |
| Output | Logo displayed on screen |

### Why RAM 98% causes lag
- Too many images/apps loaded into RAM.
- System uses Swap/Page File on Storage -> much slower.
- CPU waits for data -> UI freezes, mouse lag.

## Part 2: Technical Solution

### Relative path with `.` and `..`
```python
# If script is in project root and assets is same level
logo_path = "./assets/logo.png"

# If script is in src/ and assets is in project root
logo_path = "../assets/logo.png"

# Safer way
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
logo_path = os.path.join(BASE_DIR, "assets", "logo.png")
