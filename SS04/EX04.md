## Part 1: Analysis

### Why the machine lags
- 20 Chrome tabs + VS Code consume a lot of RAM.
- RAM is 8GB → Task Manager likely shows **RAM near 98–100%**.
- When RAM is full, Windows uses **Swap/Page File** on SSD.
- SSD is much slower than RAM → CPU waits → lag, freeze.
- CPU may also spike because many processes compete for resources.

### RAM vs Storage
| Component | Role | Analogy |
|---|---|---|
| RAM | Fast temporary workspace | Desk |
| Storage (SSD) | Slow permanent storage | Cabinet |
| Swap | Using SSD as extra RAM | Putting desk items into cabinet |

When the desk is full, you keep moving things to the cabinet and back → very slow.

### Wrong storage location
- `C:\Windows\System32\Code của tôi` is bad:
  - System folder, not for personal code.
  - Spaces and Vietnamese diacritics cause path errors.
  - Reinstalling Windows can delete everything.
  - Permission issues when running code.
