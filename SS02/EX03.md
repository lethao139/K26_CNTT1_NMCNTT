**Phần 1:**
1.IPO, vị trí dữ liệu
<!--Markdown-->
| Input | URL, thao tác người dùng (gg chrome, zalo, word), request mạng |
| Process | CPU xử lý JS/ render, RAM chứa DOM/cache, Network tải dữ liệu |
| Output | Giao diện web, zalo, word, dữ liệu gửi/ nhận |

- Vị trí dữ liệu :
  + Chrome đang active chủ yếu trong RAM
  + Zalo, Word ( một số tab nền của hdh ) vẫn trong RAM nếu đủ, nếu thiếu RAN sẽ bị đảy xuống Storage qua Page/ Swap
  + Cache, cookie, file tải: thường nằm trên Storage

2.3 hành đọng giải phóng RAM ngay
- Đóng bớt tab chrome (dùng task manager shift+esc kể kill tab ăn RAM )
- Tắt app nền k dùng (zalo, word)
- Restart chrome/ máy
Swap/ page file:
- RAM 98%-> Win dùng tạm ổ cứng làm RAM ảo
- Dữ liệu ít dùng bị ghi xuống
- HDD: chậm do seek cơ khí -> lag, chuột giật, disk dễ lên 100%
- SDD: nhanh hơn HDD nhưng vẫn chậm hơn RAM
