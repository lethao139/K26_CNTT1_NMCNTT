**Phần 1: Phân tích vấn đề**
- Thiết bị/ dữ liệu sai (kèm lí do):
  + Hóa đơn in ra giấy : Input ❌-> Output ✅ <br> (Vì in hóa đơn là bước trả kết qua cho người nhận sau khi đã nhận thông tin đầu vào người nhận qua bàn phím nhập liệu và Camera quét mã vạch.
  + Camera quét mã vạch : Process ❌-> Input ✅ <br> (Quét để lấy ttin mã vận đơn chứ k đang xử lí ttin gì hết)
  + Ổ cứng HDD lưu trữ lịch sử : Output ❌-> Progress ✅ <br> (lưu trữ trc khi xuất ttin)
**Phần 2:**
| **IPO** | Thành phần đang được phân loại |
| --- | --- |
| Input | Thông tin người nhận |
| Input | Bàn phím nhập liệu |
| Input | Camera quét mã vạch |
| Process | RAM lữ trữ tạm |
| Process | CPU xử lý cước phí |
| Storage | Ổ HDD lưu lịch sử |
| Output | Màn hình hiển thị trạng thái đơn |
| Output | Hóa đơn in ra giấy |
