# Operating System Used: Linux/macOS (Bash)

| Step |	Command |	Purpose |
| --- | --- | --- |
| 1	| mkdir drink_module |	Create the drink_module directory |
| 2	| cd drink_module |	Move into the newly created directory |
| 3	| touch coffee.txt tea.txt |	Create two empty files at once |

# Alternative for Windows (PowerShell):

| Step	| Command |	Purpose |
| --- | --- | --- |
| 1	| mkdir drink_module	| Create the directory |
| 2	| cd drink_module |	Enter the directory |
| 3	| New-Item coffee.txt, tea.txt -ItemType | File	Create two empty files |
