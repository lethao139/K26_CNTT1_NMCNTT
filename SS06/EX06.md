## Smart-Farm Setup on Windows IoT / Server Core (PowerShell)
# IPO Flow
| Stage	| Description |
| --- | --- |
| Input	| Home directory ($HOME), Public folder containing template.ps1 |
| Process |	Create smart-farm with bin, config, data; create hidden .env in config; copy & rename template.ps1 → bin\pump_control.ps1 |
| Output	| Directory tree: smart-farm\bin\pump_control.ps1, smart-farm\config\.env (hidden), smart-farm\data\; verified structure |
# Command Log
| Step |	Command	| Notes |
| 1 |	New-Item -ItemType Directory -Force -Path "$HOME\smart-farm\bin", "$HOME\smart-farm\config", "$HOME\smart-farm\data"	| Creates smart-farm and all 3 subfolders in one line | 
| 2	| New-Item -ItemType File -Force -Path "$HOME\smart-farm\config\.env"; attrib +h "$HOME\smart-farm\config\.env"	| Creates .env then marks it hidden |
| 3	| Copy-Item -Path "$env:PUBLIC\template.ps1" -Destination "$HOME\smart-farm\bin\pump_control.ps1" -Force	| Copies and renames in one command |
| 4	| Get-ChildItem -Path "$HOME\smart-farm" -Recurse -Force | Format-Table FullName, Mode -AutoSize	| Recursive listing including hidden files |
# Why `Get-ChildItem` does not show `.env`
- By default, Get-ChildItem hides files with the Hidden attribute. .env was marked hidden via attrib +h. To see it, use -Force (as in Step 4).

# Access Denied Solution
If `Copy-Item` returns “Access to the path is denied”:

- Open an elevated PowerShell: Start-Process powershell -Verb RunAs

- Or run the command directly elevated:
```bash
Start-Process powershell -Verb RunAs -ArgumentList '-NoExit','-Command','Copy-Item -Path "$env:PUBLIC\template.ps1" -Destination "$HOME\smart-farm\bin\pump_control.ps1" -Force'
Then re-run Step 3 inside the Administrator session.
```
