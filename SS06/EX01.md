## Part 1: Error Analysis

| #	| Command |	Error	| Cause |
| --- | --- | --- | --- |
| 1	| mkdir Smart Farm Project | Creates three folders: Smart, Farm, Project |	PowerShell splits arguments by spaces <br> A path with spaces must be quoted |
| 2	| cd Smart Farm Project |	Set-Location error: too many positional arguments |	cd accepts one path argument <br> Unquoted spaces are treated as separate tokens |

## Part 2: Optimized Command
`mkdir "Smart Farm Project\src\sensors\temperature"`

Or with -Force to avoid errors if it already exists:

`New-Item -ItemType Directory -Force -Path "Smart Farm Project\src\sensors\temperature"`
