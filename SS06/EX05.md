## IPO Flow
| Stage |	Description |
| --- | --- |
| Input |	Raw files in Downloads/ (.png, .jpg, .py, .tmp, etc.) |
| Process	| Filter by extension: images → media/, code → scripts/, temp → delete |
| Output |	Files moved to correct folders; .tmp files removed; no crash on name conflict |
## Commands 
```bash
# 1. Create target folders if not exist

mkdir -p media scripts

# 2. Move images (handle directory conflict safely)
for f in *.png *.jpg; do
  [ -e "$f" ] || continue
  dest="media/$f"
  if [ -d "$dest" ]; then
    mv "$f" "media/${f%.*}_$(date +%s).${f##*.}"   # rename if directory exists
  else
    mv -n "$f" media/                               # -n = no overwrite
  fi
done

# 3. Move Python files
for f in *.py; do
  [ -e "$f" ] || continue
  dest="scripts/$f"
  if [ -d "$dest" ]; then
    mv "$f" "scripts/${f%.*}_$(date +%s).py"
  else
    mv -n "$f" scripts/
  fi
done

# 4. Delete temp files
rm -f *.tmp
```
## Edge Case Handling
| Problem	| Solution |
| --- | --- |
| mv reports “Is a directory” when target name exists as a folder |	Check [ -d "$dest" ] before moving. If true, rename the file (e.g., append timestamp) then move. This avoids overwriting a directory and prevents crash. |
| File already exists as a regular file	| Use mv -n (no-clobber) to skip silently. |
| No matching files |	`[ -e "$f" ] continue` prevents errors from empty globs |
