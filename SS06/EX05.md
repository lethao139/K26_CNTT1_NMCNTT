## IPO
| Stage |	Description |
| --- | --- |
| Input |	Raw files in Downloads/ (.png, .jpg, .py, .tmp, etc.) |
| Process	| Lọc: images → media/, code → scripts/, temp → delete |
| Output | Các tệp dược chuyển đúng folder, xóa .tmp, không còn lỗi trùng tên |
## Commands 
```Powershell
mkdir -p media scripts
for f in *.png *.jpg; do
[ -e "$f" ] || continue  
  dest="media/$f"
  if [ -d "$dest" ]; then
    mv "$f" "media/${f%.*}_$(date +%s).${f##*.}"
  else
    mv -n "$f" media/
  fi    
done
for f in *.py; do
  [ -e "$f" ] || continue
  dest="scripts/$f"
  if [ -d "$dest" ]; then
    mv "$f" "scripts/${f%.*}_$(date +%s).py"
  else
    mv -n "$f" scripts/
  fi
done
rm -f *.tmp
