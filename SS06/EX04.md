# Part 1: Comparison Table

| Criteria	| C:\Users\An-K26\FarmProject\data\logs.csv (Absolute)	| ../data/logs.csv (Relative) |
| --- | --- | --- |
| Length |	Long; contains full drive, user, and folder hierarchy	| Short; only points to needed subfolder |
| Portability	| Very low; breaks on other machines, usernames, or drive letters	| High; works as long as folder structure stays same relative to script |
| Maintainability |	Hard to update if project moves	| Easy to move project without editing path |

# Part 2: Optimal Solution

- Choose: ../data/logs.csv

   - Reason: It is portable. When the project is sent to another person or moved to a different drive, the relative path still works if the folder structure is preserved.

   - Meaning of ..: It represents the parent directory (the folder one level above the current working directory).
   - Example: If the script is in FarmProject\scripts\, then ..\data\logs.csv resolves to FarmProject\data\logs.csv.
