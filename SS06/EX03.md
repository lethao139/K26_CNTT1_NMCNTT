# IPO
| Input	| Process	| Output |
| --- | --- | --- |
| Máy chủ Win không có màn hình, <br> Terminal trống, <br> Rq: - Tạo cây thư mục lồng nhau `smart-farm\data\logs` và `smart-farm\code` <br> - 3 file cấu hình: `config.json`, `sensors.py`, `.env` (file ẩn)	<br> - Sao chép toàn bộ thư mục `code` sang `backup\code_v1` (bao gồm cả nội dung bên trong) | Chạy các cmd: - New-Item -ItemType Directory -Force -Path "smart-farm\data\logs", "smart-farm\code", "smart-farm\backup" <br> - New-Item -ItemType File -Force -Path "smart-farm\config.json", "smart-farm\code\sensors.py", "smart-farm.env" <br> - Copy-Item -Path "smart-farm\code" -Destination "smart-farm\backup\code_v1" -Recurse -Force	| Cây thư mục: smart-farm\code, smart-farm\data\logs, smart-farm\backup\code_v1; các tệp: config.json, sensors.py, .env |
# Lệnh 
```Powershell
New-Item -ItemType Directory -Force -Path "smart-farm\data\logs", "smart-farm\code", "smart-farm\backup"
New-Item -ItemType File -Force -Path "smart-farm\config.json", "smart-farm\code\sensors.py", "smart-farm.env"
Copy-Item -Path "smart-farm\code" -Destination "smart-farm\backup\code_v1" -Recurse -Force
