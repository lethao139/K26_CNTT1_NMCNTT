## Smart-Farm Infrastructure Setup (PowerShell)
# IPO Diagram
| Input	| Process	| Output |
| --- | --- | --- |
| Headless Windows server; terminal access; requirement to create code, data/logs, backup; create 3 config files; copy code to backup\code_v1	| Run PowerShell commands to create nested directories, create files, and copy folder recursively	| Directory tree: smart-farm\code\, smart-farm\data\logs\, smart-farm\backup\code_v1\; files: config.json, sensors.py, .env |
# PowerShell Commands
| #	| Purpose |	Command |
| --- | --- | --- |
| 1	| Create nested folders + backup folder in one line	| New-Item -ItemType Directory -Force -Path "smart-farm\data\logs", "smart-farm\code", "smart-farm\backup" |
| 2	| Create 3 files at once |	New-Item -ItemType File -Force -Path "smart-farm\config.json", "smart-farm\code\sensors.py", "smart-farm\.env" |
| 3	| Copy code to backup\code_v1 recursively |	Copy-Item -Path "smart-farm\code" -Destination "smart-farm\backup\code_v1" -Recurse -Force |
