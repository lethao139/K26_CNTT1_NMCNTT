# How to install VS code ( for student )

## 5 Step:

### 1. Download
- Click [code.visualstudio.com](https://code.visualstudio.com/) 
- Download version fix with your OS (Windows/ macOS/ Linux)
- <img width="209" height="366" alt="image" src="https://github.com/user-attachments/assets/9a1bf718-3ab3-4fb0-8a9b-ffec337238e5" />

### 2. Install
- Run the installer and follow the steps to complete the installation
- <img width="207" height="359" alt="image" src="https://github.com/user-attachments/assets/6b4d6414-90f9-4709-8328-5b02e5d64b04" />

### 3. Open Terminal
- Open terminal ( Crt +` or terminal->new terminal)
- <img width="219" height="377" alt="image" src="https://github.com/user-attachments/assets/c8744254-a923-48d3-b275-3c0889302ccd" />

### 4. (Optional) Add to PATH
- Install the code command to open VS code from any folder (optional but recommended)
```bash
code --install-extension ms-vscode.vscode
```
- <img width="222" height="383" alt="image" src="https://github.com/user-attachments/assets/7d94100f-7d45-4491-b46b-cb8b42a04734" />


### 5. Verify
- Verify the installation by checking the version
```bash
code --version
```
result :
```text
1.89.1
```
