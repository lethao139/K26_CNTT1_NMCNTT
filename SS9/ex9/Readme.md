## 🚀 Hướng dẫn Gia nhập

1. **Fork** repository của CLB về tài khoản GitHub cá nhân.
2. **Clone** repository về máy:
   ```bash
   git clone https://github.com/ptit-antiti-club/onboarding.git
   cd onboarding
   ```
3. Cấu hình thông tin Git cá nhân:
   ```bash
   git config --global user.name "Ho Ten Cua Ban"
   git config --global user.email "email@ptit.edu.vn"
   ```
4. Tạo nhánh mới và thêm tên bạn vào file `members.md`:
   ```bash
   git checkout -b add-member-ho-ten
   echo "- Ho Ten - K26 - CNTT" >> members.md
   git add members.md && git commit -m "Add new member"
   git push origin add-member-ho-ten
   ```
5. Mở **Request** và chờ Ban Kỹ thuật review.
