# Dự án website Trung tâm tiếng Anh (TTA)
## Giới thiệu
**Dự án xây dựng website Trung tâm tiếng Anh TTA nhằm hỗ trợ quản lý học viên và đăng ký khóa học** *nhanh chóng và thuận tiện*.
## Cấu trúc thư mục
Thư mục|Nội dung
|-|-|
|archive| chứa bản sao logo trung tâm, ảnh lớp học|
|data| chứa danh sách học viên khoá 3, bảng học phí tháng 10|
|media| chứa logo trung tâm, ảnh lớp học|
|docs| chứa lịch học|
|logs| chứa các bản báo cáo thanh toán, truy cập website|

 ## Quy trình đăng ký học tại TTA
 1. Chọn khóa học phù hợp
 2. Điền thông tin đăng ký
 3. Xác nhận học phí và số tháng học
 4. Hoàn tất đăng ký
 **Lệnh liệt kê nội dung dự án
  ``` powershell
get-childitem -recurse -force
```
