**Part1** 

1. Wrong type of path: <br>
`C:\Users\Admin\Desktop\CineBook_Project\images\poster.JPG` is an absolute local path on a personal computer. When the website is deployed to a server, this path no longer works because the server does not have `C:\Users\Admin\....` The browser also cannot directly access the server’s local drive using that path.

2. Wrong uppercase/lowercase file extension: <br>
The code calls `poster.JPG`, but the actual file is `poster.jpg`. On many servers, especially Linux-based ones, filenames are case-sensitive, so `poster.JPG` and `poster.jpg` are treated as different files. As a result, the image returns a 404 error and shows a broken image icon.

3. Additional issue: <br>
Using Windows-style backslashes `\` instead of forward slashes `/` in web paths can also cause problems.
