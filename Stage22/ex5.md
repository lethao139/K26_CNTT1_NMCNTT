1.mẫu bug report template (bắt buộc điền)

- context: môi trường làm việc (hệ điều hành, phiên bản docker, lệnh đang chạy)
- expected: kết quả mong đợi (vd: container khởi chạy thành công)
- actual: kết quả thực tế (vd: báo lỗi port đã bị chiếm)
- log: mã lỗi nguyên văn hoặc ảnh chụp màn hình

2.quy trình 3 bước tự xử lý 80% vấn đề trước khi hỏi

- bước 1 googling: bóc tách tên phần mềm + mã lỗi nguyên văn, dùng toán tử `site:`, `" "`, `-` để lọc kết quả nhiễu
- bước 2 community search: lên stackoverflow hoặc github issues dùng từ khóa tìm kiếm, đọc kỹ các comment có nhiều upvote hoặc workaround
- bước 3 ai translation: dùng prompt 3 thành phần (ngữ cảnh - lỗi - yêu cầu) để nhờ ai giải thích lỗi và đưa ra cách sửa an toàn
