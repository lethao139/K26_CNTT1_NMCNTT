# 1.báo cáo phân tích ipo

- input: câu lệnh lạ do ai đưa ra để sửa lỗi path not found
- process: bóc tách từ khóa lệnh -> google với cú pháp `site:stackoverflow.com "từ_khóa_lệnh"` hoặc `site:python.org` -> đối chiếu xem lệnh có phá hoại file hệ thống hay không
- output: kết luận an toàn (chạy được) hoặc không an toàn (hủy bỏ do ai ảo giác)
